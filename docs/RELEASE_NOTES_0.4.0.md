# AI University v0.4.0

数学系列网站重做为可探索的数学展览馆。完整 Calculus I 保留 7 章、35 节、70 例题、175 道练习；固定教材版本仍为 v0.2.0。网站保持纯静态，所有交互在浏览器运行。

- 全幅三维数学首屏：曲面、环面、螺旋，支持形态过渡、参数变化、拖动、键盘操作和暂停。
- 六个数学方向、完整教材展陈及可操作学习演示连接成连续首页。
- 重新编排书库、出版状态与筛选；规划教材保持真实状态。
- 阅读页加入章节视觉层级与专注阅读，保留完整正文、推导、例题、练习、知识连接及手机目录。
- 按需加载三维模块；降低动态效果偏好关闭自动旋转，视口外暂停渲染。

验证：`npm run check` 通过，20 项内容与数学检查通过；实际浏览器检查全部 35 节在桌面/手机共 70 个正文视图，9 个主要入口在三种宽度共 27 个视图，三种首页形态的六个参数端点及阅读控件。
