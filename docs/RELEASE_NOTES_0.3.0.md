# AI University v0.3.0

本版改进完整 Calculus I 的解释、独立尝试和空间演示。网站仍是纯静态：无实时 AI、API 密钥或服务端。

- 35 节讲解重写为简明结论、直觉和三个具体问题；保留完整定义条件、推导、70 道例题与 175 道练习。
- 新增 35 个概念检查及逐题反馈、35 个演示预测问题。例题步骤默认收起，方便先独立尝试。
- 加入圆盘、圆环、圆柱壳、旋转曲面的真实 3D，支持旋转、缩放、截面、角度、网格、视角和播放速度；原始 2D 视图继续可用。
- 极限加入孔洞/跳跃对比；导数加入光滑曲线/绝对值尖点对比。
- 数学系列首页增加三种互动预览；已出版与规划教材继续明确区分。
- 新增学习方法与参考资料页及来源说明，依据 OpenStax、Active Calculus、3Blue1Brown、MIT OCW、IES、主动回忆综述、PhET 和 CMU 的相关材料改进学习设计。
- Calculus I 固定书稿更新至 v0.2.0。补充极限定义、隐函数、换元和旋转体的条件表述。

验证：`npm run check` 通过，16 项内容与数学检查通过；实际浏览器检查全部 35 节正文与演示、手机全部 70 个视图、三种宽度的 27 个代表视图及完整下载书稿。

教材由 AI 编写，尚未逐节人工审校或进行读者学习效果实验。3D 需要 WebGL2；实现了不可用时回到 2D 的入口，未在不支持 WebGL 的真实设备上验证。正文不加载 3D 模块；模块按需加载，构建仍有体积提示。
