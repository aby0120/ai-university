# AI University v0.2.0

AI University 现在拥有完整的静态教科书网站结构：独立首页、书库、教材主页、七个章节主页、三十五个知识点页面、可筛选和分页的实验室与练习中心、全文搜索、知识索引、学习记录、指南、下载、贡献、版本与本地数据管理。

阅读体验重新设计：更清楚的正文层级，嵌入式演示，页内定位，定义条件、分步推导、逐步例题与误区，收藏、较大字号、已读标记和上下节翻页。练习可以逐题进行或连续查看，保留提示、完整解答和本地数值检查。

完整 Calculus I 内容继续包含 7 章、35 节、70 例题、175 练习与解答。教材为 AI 编写的固定版本；本轮修正了导数演示中切线颜色的说明。所有读者端功能均在静态浏览器中运行，没有模型 API、账户或服务器功能。

验证：内容、公式、类型、整本生成、构建和 11 项内容/数学测试通过。应用内浏览器检查全部 35 节、滑块最小/最大边界、60 个手机页面与 10 个平板页面，以及搜索、筛选、分页、练习、收藏和记录导入/导出。详情见 docs/REDESIGN.md。

Assets: full source ZIP, built static website ZIP, and complete Markdown textbook. Run the website ZIP through a static HTTP server; opening index.html as a file URL is not supported.
