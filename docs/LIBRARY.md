# 数学系列与书库

AI University 的首页是数学系列入口。单本教材有各自的教材主页；Calculus I 是首本已出版教材，不是整个网站的范围。

`packages/content/library.json` 定义数学方向和教材目录。首页方向卡、出版数量、已出版书架、书库筛选及后续教材规划均读取这一份目录。`schemas/library.schema.json` 区分 `published` 和 `planned`：规划条目没有阅读链接、统计数量或空白正文。

当前规划六个方向：微积分、线性代数、微分方程、概率与统计、离散数学、实分析。它们是可调整的系列规划，没有承诺出版日期或固定顺序。

## 新增规划

在目录的 `volumes` 中增加唯一 ID、所属方向、中文标题、英文标题、简介、先修读者与拟覆盖范围，设 `status: "planned"`。如需新方向，先在 `areas` 中定义它。首页和书库会自动显示该条目；不要创建占位教材路由。

## 出版下一本

先完成该教材的 canonical 目录、所有章节、练习解答、演示与下载稿。当前章节加载器和学习记录仍服务于 Calculus I；下一本出版时须接入按书 ID 区分的内容加载、章节/知识点路由、下载入口和本地记录，再把目录状态改为 `published`，填写实际 `route`、封面公式和内容统计。

同步扩展 `scripts/validate-content.mjs` 中已实现教材的校验集合，并检查正文、打印稿、习题与先修图。本次建立的是可扩展的系列展示与书库，不以添加一个目录条目代替整本教材的实现。

执行 `npm run check`，检查首页、书库方向与出版状态筛选，以及新教材的移动端阅读，然后按 [发布流程](RELEASING.md) 发布。
