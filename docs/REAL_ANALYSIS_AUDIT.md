## 范围与产物

## 数学与教学检查

- 从上确界作正负小扰动证明平方根存在，未循环使用后面的介值定理；补出正成员与具体扰动量。
- 严格误差下取倒数数列截断，区别“全部尾项”和“无限多项”；Cauchy 反例比较倍增指标，不能只看相邻差。
- 调和级数用倍增块证明发散；平方倒数用望远镜比较；幂次级数补出二进块的几何上界。比值与根值在临界一处不判断。
- 开闭性说明环境；区分闭包、孤立点和去心聚点；紧致性量化所有开覆盖。对角线映入三进制实数时补出首个差异位与尾部差的严格间隙。
- 介值与极值定理分清连通和紧致；一致连续反例的输入差趋零但输出差趋二。
- 可导不等于导数连续。Darboux 以扣去目标斜率后的内部极值证明，未假设导数连续。Taylor 保留余项条件与光滑不解析反例。
- Darboux 矩形取解析确界，阶跃触碰跳点端值也计入振幅。稠密零一函数不画成有限样点冒充真实图。
- 基本定理保留内点连续、Riemann 可积及端点连续条件；积分线性、加性、标记和等价性另有补充。
- 区分逐点与一致收敛、有限区间积分与无穷区间积分、函数一致收敛与导数一致收敛；导数交换包含一点函数值收敛条件。
