# 教材内容规范

## 写作方式

第一句话说明知识点解决什么问题。先用可检验的直觉给读者抓手，再给精确定义与条件。术语出现时解释用途，不用复杂词汇替代解释；也不把必需的数学条件当作可删掉的“壁垒”。

每节增加一个三选一概念检查（含条件反馈）和一个演示预测问题。例题可先尝试，再展开解法；独立练习仍提供提示与完整解答。

每节至少包含三个正文段落、三个推导步骤、两个逐步例题、两个误区和四道带完整答案的练习。不是列一张公式表就算完成。例题包含基础与迁移；练习按识别、计算、应用与条件检查逐渐展开。

## Learning object 字段

| 字段 | 用途 |
|---|---|
| concept / intuition | 核心意思与直觉 |
| learningCheck | 针对具体误区的提问、三个选项、正确索引与解释 |
| body / objectives | 系统正文与学习目标 |
| formalDefinition | 定义或定理、LaTeX、全部适用条件 |
| derivation | 分步解释为何成立，不只展示结果 |
| interactiveVisual | 对应模式、数学模型、预测问题与观察任务 |
| workedExamples | 题目、逐步计算、答案与必要单位 |
| commonMistakes | 错误想法与具体纠正 |
| practice | 题目、提示、答案、完整解法与难度 |
| prerequisites | 本卷内已出现的前置概念 ID |
| difficulty | 1–6 的相对认知负担，非标准化成绩 |
| misconceptionTags | 与本节具体误区连接的标签 |
| provenance / sources | AI 生成状态、版本、是否人工审校及来源 |

## 数学表达

- 区分函数值、有限极限与无穷趋势；0/0 不当作数值。
- 导数、原函数与换元明确所讨论区间。反函数注明分支；对数与根式注明定义域。
- 定理附连续、可导与闭区间等条件。零导数只是极值候选，二阶零点只是拐点候选。
- 区分近似与等式、带符号积分与面积、位移与路程、旋转侧面与含端盖总面积。
- 练习答案可由原问题复算；符号答案建议通过求导、代回或第二种解法确认。
- `numericAnswer` 只用于明确的标量题，误差容许约为 1e-5；不把表达式字符串匹配伪装成数学自动评分。
