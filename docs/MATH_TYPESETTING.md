# 数学排版检查 · v0.5.1

日期：2026-10-11。教材版本：v0.2.1。

## 修复范围

35 节教材的题干、选项、解释、推导、例题、练习、提示、章节复习和综合测验都使用明确的数学标记。分数用 `\\frac`，根式用 `\\sqrt`，上下标、函数、积分和单位使用正式数学排版。网页和整本打印版共享同一个分段与显示规则；搜索、页面标题和原生控件名称保留可读文本。

修复用户指出的定义域题：分数和根号成为真实数学结构，三个选项也统一排版。选项的正确答案仍是 B。长公式在自身区域滚动，手机页面不随公式变宽。图示的公式标题与实际显示模型保持一致。

内容修订中还将章节复习里的基本极限补齐为带趋近条件的极限式，避免把极限值写成普通恒等式。积分号、分母边界、单位及分数指数逐项检查。教材结构、题目 ID、数值答案和正确选项没有改动。
